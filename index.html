Warm Burrow Publisher
Internal publishing tool · for one channel

A small tool that publishes our own episodes.

Warm Burrow Publisher uploads finished video episodes to the Warm Burrow Stories YouTube channel and schedules when each episode goes live. It runs on the channel owner's computer from the command line.

The channel this tool publishes for: papercraft tea house stories, 24 seconds per episode.

What the tool does

  • Uploads a finished video file (.mp4) to the owner's own channel.
  • Sets the title, description, tags, category and thumbnail.
  • Schedules publication: the video is uploaded as private with a publish time, and YouTube makes it public automatically at that minute.
  • Keeps a local record of what was uploaded, so the same file is never uploaded twice.

How it works

StepWhat happens
1The owner runs node publish/auth.mjs once and approves access in Google's consent screen, choosing the correct YouTube channel.
2For each episode the owner runs node publish/upload.mjs --ep episodes/EP002-tea-and-rain.
3The tool uploads the file and sets the scheduled publication date. YouTube publishes it.

The tool refuses to upload if the authorised channel is not the one recorded for this project — a safeguard for accounts that manage more than one channel.

Permissions and data

Warm Burrow Publisher requests two YouTube scopes:

youtube.upload youtube

  • youtube.upload — upload the owner's own video files.
  • youtube — set the thumbnail, add the video to the channel playlist, and read the channel name to make sure uploads go to the right channel.

No viewer data, subscriber data, comments or analytics are read. Nothing is shared with third parties. Details: Privacy Policy.

Who it is for

One person: the owner of the Warm Burrow Stories channel. There is no sign-up, no public account, no multi-tenant use, and no other users' data is ever accessed. The tool is not distributed as a product.
