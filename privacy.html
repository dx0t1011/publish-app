Privacy Policy

Warm Burrow Publisher · last updated 20 November 2026

Warm Burrow Publisher ("the application") is a command-line tool used by the owner of the YouTube channel Warm Burrow Stories to upload and schedule that channel's own videos. This policy explains what data the application handles and how.

1. This application uses YouTube API Services

The application uses YouTube API Services. By using the application the owner agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

2. What the application accesses

  • YouTube Data API v3 with the scopes https://www.googleapis.com/auth/youtube.upload and https://www.googleapis.com/auth/youtube.
  • Used to: upload a video file to the owner's own channel; set title, description, tags, category and thumbnail; schedule the publication time; add the video to the channel's own playlist; read the channel name and statistics to confirm that uploads target the correct channel.

3. What the application does not do

  • It does not read, collect or store viewer, subscriber, comment or analytics data.
  • It does not access Gmail, Google Drive, Calendar, Contacts or any other Google service.
  • It does not serve third parties. There is no sign-up, no public account, and no other users.
  • It does not sell, rent or share data with advertisers or any third party.

4. What is stored, and where

  • A Google OAuth refresh token for the owner's own channel. It is stored only on the owner's computer in a local file with owner-only permissions (publish/.env), and is never committed to a public repository or sent anywhere except to Google's OAuth endpoint (oauth2.googleapis.com).
  • A local log of uploaded videos (video id, publication time, file fingerprint) kept for the owner's records.
  • Video files stay on the owner's computer. The uploaded copy is stored by YouTube under the YouTube Terms of Service.

5. Data sharing

No data is shared with third parties. Requests are sent only to Google APIs (googleapis.com, oauth2.googleapis.com).

6. Retention, deletion and revoking access

  • Access can be revoked at any time at myaccount.google.com/permissions.
  • Deleting the local .env file removes the stored token from the computer.
  • Uploaded videos can be deleted by the owner in YouTube Studio at any time.
  • The local upload log can be deleted at any time; it lives only on the owner's computer.

7. Security

The token is stored with owner-only file permissions and transmitted only over HTTPS to Google. The application is not installed on shared or public machines.

8. Children

The application is not directed to children and is not used by third parties.

9. Changes

If this policy changes, the updated version is published on this page with a new date.

10. Contact

Questions about this policy or data handling — write to bs2accc@gmail.com, or open an issue at github.com/dx0t1011/publish-app/issues.
